# Agent Harness 手写区

这里仅保留手写入口，不放参考实现。

- `src/agent/`：模型无关的 Agent Harness。
- `src/agent/tools/`：Harness 调用的具体工具。
- `src/tests/agent/`：验收测试，手写过程中逐步跑通。
- `src/ai/ingest/`：Harness 完成后再实现的“材料整理”业务层。

实现纪律：

1. 先定义内部协议，再连接模型和工具。
2. 模型输出和工具参数全部视为不可信输入。
3. 工具失败转换为结构化观察，不让一次失败直接炸掉循环。
4. Agent 不拥有直接写入导图的能力，只能产出候选。
5. 每完成一个文件，运行对应测试；不要一次写完所有文件。
