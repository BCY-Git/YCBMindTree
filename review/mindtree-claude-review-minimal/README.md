# MindTree Minimal（无依赖审核包）

这是从 MindTree 的核心“树状导图编辑”体验提炼出的独立版本，供网页端 Claude Code 快速审核。它刻意不复用主项目源码，也不需要安装 Node.js、npm、React、Tauri 或任何第三方包。

## 运行

直接双击打开 `index.html`，或将整个目录拖入浏览器。数据仅保存在当前浏览器的 `localStorage` 中。

## 已覆盖的核心流程

- 创建、改名、删除节点；添加子节点/同级节点；拖放到节点上以调整父子关系
- 分支折叠与展开、关键词搜索定位、完整导图适应视图
- 自动树布局、节点位置微调，以及选中节点或整图的一键位置重置
- 左侧大纲与节点属性编辑；节点创建/更新时间；长主题悬停提示
- 可撤销/重做（`Ctrl/⌘+Z`、`Ctrl/⌘+Shift+Z`），导入和新建前自动保留可撤销快照
- 浏览器本地自动保存、存储失败告警、多标签页修改提示，以及带树结构一致性校验的 JSON 导入/导出
- JSON 备份和 SVG 图片导出

## 有意移除的部分

原项目的 React/React Flow 画布、Tauri 桌面壳、IndexedDB、账户与云同步、AI 助手、附件、版本历史、项目管理、任务、演示模式、导入导出格式扩展和服务端均不在此包内。它们不属于本次“零依赖核心编辑器”审核范围。

## 建议审核重点

1. 数据模型中的 `parentId` / `childIds` 双向关系是否在编辑、撤销/重做和拖拽重组后保持一致。
2. 删除子树、导入 JSON、本地存储失败、跨标签页冲突和导出边界条件。
3. SVG 渲染、缩放/视图边界、键盘操作及可访问性是否有明显问题。
4. 这一极简架构是否适合成为原项目 Core Domain 的参考实现。

完整项目仍在本仓库根目录；此目录是独立的、可直接分享的审核快照。
