# 审核问题修复对照

本文件对应 `MindTree-Minimal-审核报告.md` 的 P0–P3 清单。

| 报告项 | 已完成的改进 |
| --- | --- |
| P0-1 存储失败 | `save()` 捕获异常、记录控制台错误，并以持续的红色状态栏提示立即导出 JSON。 |
| P0-2 多标签页覆盖 | 监听 `storage` 事件，显示冲突提示；用户可载入另一标签页的最新版本或保留当前版本。 |
| P0-3 无撤销 | 80 步内存快照历史、工具栏按钮及 `Ctrl/⌘+Z` / `Ctrl/⌘+Shift+Z`。 |
| P0-4 导入覆盖 | 导入和新建均明确确认，并在替换前保存可撤销快照。 |
| P1-5 重组分支 | 将节点拖放到另一节点上可变为其子节点；会阻止根节点移动、原父节点重复放置和环。 |
| P1-6 偏移失控 | 提供选中节点和全图的“重置位置/自动排列”。 |
| P1-7/P1-8 视图迷路 | `fitView()` 基于实际可见节点包围盒缩放居中；平移保持至少一部分导图留在画布内。 |
| P1-9 搜索 | 左栏关键词搜索；选中结果会展开祖先路径、选中并居中。 |
| P1-10 折叠一致性 | 添加子节点时明确自动展开并给出状态提示；同级节点保留现有分支状态。 |
| P2-11 快捷键 | 破坏性快捷键仅在画布获得焦点时生效；输入框内不拦截键盘操作。 |
| P2-12 改名重渲染 | 改名只刷新画布/大纲/搜索结果，不重建属性输入框。 |
| P2-13/P2-14/P2-15 反馈 | SVG 原生 tooltip、停留 2.8 秒的状态消息、删除后父节点居中。 |
| P3-16～P3-20 | 使用 `crypto.randomUUID()`、移除死空状态、保存更新时间、SVG 导出及规整导出文件名。 |

## 仍然有意保留的边界

- 撤销历史仅保存在当前标签页内，刷新页面后清空；持久化数据仍保留。
- 多标签页提供冲突可见性与手动选择，不实现自动合并。
- SVG 导出的是当前可见分支；已折叠分支维持折叠状态。
