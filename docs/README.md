# MindTree 文档

MindTree 是一个本地优先、键盘优先的个人树形思维导图工具。本文档集把产品方案收敛为可实施的第一阶段工程约束。

- [产品需求与 MVP](./product-requirements.md)：第一阶段范围、用户流程与验收条件。
- [技术架构](./architecture.md)：分层、数据模型、命令系统、布局与持久化边界。
- [实施路线](./implementation-plan.md)：当前迭代的交付范围和后续阶段。
- [智能沉淀与协作设计包](./mindtree-agent-design-v0.3/README.md)：0.3 的产品定位、MVP 协议、交互与实施约束。
- [0.3.0 发布说明](./release-0.3.0.md)：智能沉淀、跨导图回流与协作检查点。
- [0.4.0 发布说明](./release-0.4.0.md)：将协作检查点转化为决策记录和知识卡。

## 当前实现范围

当前工程优先交付一张可编辑、自动布局的右向树：创建、编辑、删除、折叠、键盘导航、撤销重做，以及浏览器本地自动保存。导入导出、双向树、手动偏移和桌面封装会在核心链路稳定后加入。
