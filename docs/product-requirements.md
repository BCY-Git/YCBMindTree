# MindTree：产品需求与 MVP

## 产品定位

MindTree 是面向个人工作的本地优先思维导图编辑器。它不复刻完整 XMind；第一目标是让用户用键盘快速整理一棵可持续编辑、可恢复的树。

## 第一阶段目标

用户可以在一个浏览器标签中完成以下闭环：

1. 新建一张导图并编辑中心主题。
2. 使用 Tab 创建子节点、Enter 创建同级节点。
3. 用方向键在相邻节点间移动，用 Space 折叠或展开分支。
4. 修改、删除节点，并使用撤销与重做修正操作。
5. 刷新页面后恢复最近编辑的导图。

## 本迭代范围

### 必须具备

- 单文档、右向树形自动布局
- 主题编辑、子节点/同级节点创建、删除子树
- 节点选中、双击或 Enter 编辑、折叠/展开
- 节点与画布右键菜单：就地创建、编辑、折叠和删除，避免操作时反复移动到工具栏
- `Cmd/Ctrl + K` 命令面板：按名称查找当前节点可执行操作，并展示快捷键
- 结构编辑：`Shift + 拖动`重挂分支；`Alt + ←/→`调整层级；`Alt + ↑/↓`调整同级顺序；支持复制、剪切、粘贴完整分支
- 大图导航：支持前往中心主题、折叠/展开当前节点全部次级分支；选中节点以单一实线外框标识，不影响其他分支的可见性
- 关系线：可在任意两个可见节点间建立独立的横向关系，编辑说明或删除；关系不改变父子结构，删除节点时自动清理相关关系
- 布局恢复：支持重置单节点人工偏移；自动排列时保存当前自由排布记录，并可从右键菜单恢复该记录
- 快捷键：Enter、Tab、Backspace/Delete、Space、方向键、Cmd/Ctrl + Z、Cmd/Ctrl + Shift + Z
- 文档修改历史与浏览器本地自动保存
- 基础布局设置：层级间距、同级间距
- AI 助手：左侧提供兼容 OpenAI Chat Completions 的服务地址、模型名与 API Key 配置；配置仅保存在当前浏览器，只有用户主动提问时才将当前导图上下文发送至其指定服务
- AI 分支生成：用户可让 AI 围绕当前选中节点生成候选子树；候选内容须先通过预览与确认，确认后作为一次可撤销的树命令插入导图
- 工作区导航：左侧按项目、导图记录和助手分区；支持新建导图、查看历史导图、创建分类、按分类筛选，以及为当前导图指定分类
- 账户入口：侧栏底部展示本地身份、设置与帮助入口；真实登录/退出与云端同步账号在同步服务接入后启用
- 右侧主题面板：内置协调的画布、节点、分支颜色主题；主题与文档一同本地保存
- 节点拖动用于保存个人位置微调；拖动根节点时整张导图保持相对位置并整体移动；拖动不改变父子结构

### 明确延后

- 多文档管理、文件系统保存、崩溃恢复快照
- Markdown、OPML、SVG/PNG 导入导出
- 结构拖拽、人工位置偏移、左右双向布局
- 节点样式覆盖、附件、全文搜索、AI、CLI、MCP、Tauri

## 交互原则

- 键盘优先：高频结构操作不依赖工具栏。
- 编辑状态隔离：正在输入时，普通字符不得触发画布命令。
- 结构优先：画布的连线与位置是文档树的派生结果，不是事实来源。
- 保守删除：根节点不可删除，删除其他节点即删除其完整子树。

## 视觉与交互方向

- **视觉主张：** 像一张安静、可专注的工作台；暖白画布、墨色文字和单一松绿强调色，信息层级靠留白与连线建立。
- **内容结构：** 顶部提供文档和撤销操作；中心画布承载工作；右侧只展示当前选中节点的必要属性。
- **动效原则：** 节点进入和布局变化采用短促缓动；节点悬停与选中强化可操作性；缩放和平移保持直接、无装饰。

## 验收条件

- 任意有效节点均可从根节点访问，且父子引用始终一致。
- 自动布局中，显示节点不重叠，兄弟节点顺序稳定。
- 连续文本编辑可作为一次撤销操作恢复。
- 有效修改在短暂防抖后写入本地；刷新后可读取。
