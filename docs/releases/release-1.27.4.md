# MindTree 1.27.4

AI 助手面板参照主流嵌入式聊天（Cursor / ChatGPT / v0 / assistant-ui）重设计。

## 改造

- 三段式结构：固定头部 / 可滚动消息流 / 贴底输入区，内容少时输入区也钉在底部。
- 消息扁平化：AI 消息去掉气泡边框与头像，全宽正文排布，保留轻量「MindTree Agent」身份标识与悬停显现的复制按钮；用户消息右对齐浅色气泡（fit-content，最大 85% 宽），去掉过饱和的深绿实心气泡和「你」头像。
- 空状态：建议操作从 emoji 胶囊换成 Radix 线性图标的两列卡片，边框更淡。
- 输入区：Cursor 式单卡片 composer —— textarea、截图入口、模型选择、发送按钮同处一个圆角卡片内；Enter 发送、Shift+Enter 换行（兼容中文输入法组词）；发送按钮为 32px 图标钮，无可发送内容时静默置灰；去掉原生 textarea 缩放手柄。
- 头部 tab 选中态降噪：只变图标色，不再有实底色块。
- 所有规则收进 readability.css 末尾，解决与旧可读性覆盖层的加载顺序冲突。

验证：前端 397 用例与类型检查通过；浏览器实测栅格对齐（欢迎区/建议/输入卡同一边距）。
