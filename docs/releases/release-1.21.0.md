# MindTree 1.21.0

## 工作区与计划

- 新增项目库、导图归属与跨导图计划汇总。
- 新建导图会继承当前项目，导图备份也会保留项目关系。

## 编辑与资源

- 节点支持直接粘贴剪贴板图片，并在节点内自适应展示。
- 图片可从四个角等比例缩放，尺寸会随导图元数据保存。
- 优化桌面工具栏、移动端工具面板与工作区搜索入口。

## 工程与服务

- 新增可审计的 Agent Harness 基础能力与统一 API 客户端。
- 同步服务迁移为模块化 Nest API，保留认证、配对、MCP 与 AI 代理能力。
- 前端测试目录集中至 `src/tests`，便于按模块执行回归验证。
