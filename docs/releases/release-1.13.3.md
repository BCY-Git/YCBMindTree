# MindTree 1.13.3

1.13.3 修复节点属性侧栏中备注幽灵续写的排版与裁剪问题。

## 修复内容

- 普通备注输入不再使用透明文字与镜像层，恢复浏览器原生文字和光标渲染。
- AI 建议镜像只存在于备注输入框内部，长内容不会覆盖下方提示或其他属性界面。
- 统一镜像文字与 textarea 的字号、行高和内边距，避免光标与可见文字错位。
- 同步 textarea 与 AI 建议镜像的横向、纵向滚动位置。

## 验证

- 前端：48 个测试文件、177 个测试通过。
- 服务端：5 个测试文件、19 个测试通过。
- TypeScript 与 Vite 生产构建通过。
- Chromium 实测镜像层与 textarea 均为 14px 字号、21px 行高和 9px 内边距，输入区域裁剪生效。
