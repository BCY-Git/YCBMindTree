# MindTree 1.18.0

## 本次更新

- 右侧节点属性新增“项目”页：选中任一项目节点或分支，即可查看该范围内的项目状态。
- 状态视图集中呈现任务完成进度、正在推进事项、阻塞与风险、最近成果、已确认决策和下一步。
- 项目状态会汇总已确认的智能沉淀与活跃协作会话，但不会复制、覆盖或改写原始日报、随手记和项目节点。
- 对来自日报、会议记录等沉淀出的成果、问题和决策，可点击“查看来源”回到原始记录节点。
- 提供手动刷新，重新读取本地已确认沉淀和协作会话；刷新本身不改变导图。

## 稳定性边界

- 只有用户确认并实际写入的沉淀会进入项目状态；待审查、忽略或未写入的 AI 建议不会被当作项目事实。
- 项目状态是当前选中分支的派生视图，不新增第二份项目数据，也不影响导出、同步和普通导图使用。
- 任务进度继续以节点既有的任务状态为准；项目工作阶段不会替代任务状态。
