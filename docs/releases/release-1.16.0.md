# MindTree 1.16.0

## 本次更新

- 新增三档语义缩放：概览层突出主题与树形结构，结构层保留简化任务提示，工作层显示完整节点能力。
- 缩放层级使用带缓冲的双阈值切换，避免触控板停在边界附近时反复闪烁。
- 概览和结构层不再展示完整任务按钮、优先级、标签、标记、图片预览及关系锚点，降低大图远景杂讯。
- 选中或正在编辑的节点会自动恢复完整能力，不需要先放大画布才能继续操作。
- 左下角新增“层”控制，可随时关闭语义缩放；用户选择会保存在本机。

## 稳定性边界

- 语义缩放只替换节点的信息层，不参与树形布局计算。
- 切换层级不会改变节点坐标、节点尺寸或现有连接线路径。
- 文档数据和完整导出不依赖当前画布缩放层级。

- 服务端：5 个测试文件、19 项测试全部通过。
