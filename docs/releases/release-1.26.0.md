# MindTree 1.26.0

附件上云：图片与 HTML 附件不再只存本机。

## 服务端

- 新增附件字节端点：`PUT/GET /api/v1/documents/:documentId/attachments/:attachmentId`（Bearer 认证、15MB 上限、MIME 白名单、字节落文件系统）。
- 文档快照保存后自动清理不再被引用的附件字节。
- MCP 新增 `mindtree_attach_image`：agent 可直接把 base64 图片挂到节点（元数据版本锁写入 + 字节保存一次完成）。

## 同步链路

- 上传：推完文档结构后自动补传云端缺失的附件字节（HEAD 探测，幂等）。
- 拉取：落地远端快照后自动下载本机缺失的附件字节。
- 懒加载兜底：打开导图时本地没有字节的附件会自动从云端拉取并缓存到本机。

验证：服务端 33 用例、前端 390 用例全部通过。
