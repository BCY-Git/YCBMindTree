# MindTree 0.5.0

0.5.0 为外部 Agent 增加受控的 MCP 智能沉淀闭环，同时保持“未经确认不写入”的产品边界。

## 新增

- MCP 有限子树分析上下文。
- MCP 候选协议校验与持久化预览批次。
- 待审查和已应用批次查询。
- 一次性确认令牌、显式确认和版本冲突保护。
- 导图更新与批次状态的 SQLite 原子事务。

## 边界

- MCP 第一版只支持单目标导图计划。
- 跨导图沉淀继续由客户端 Dexie 事务处理。
- 服务端批次不会伪装成客户端本地收件箱候选。
- 不支持删除、移动、合并或无人确认写入。

## 版本

- MindTree 客户端：0.5.0。
- MindTree Server / MCP：0.2.0。
