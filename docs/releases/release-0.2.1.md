# MindTree 0.2.1：关系线与结构交互

本版重点是让“父子结构”和“跨节点联系”成为两套清晰、互不干扰的能力。

## 本版交付

- 选中任意节点后，顶部中央的“建立联系”可用；一次操作会新建一个自由主题并建立默认关系，撤销时两者一起回退。
- 关系目标可在右侧面板改为任一已有节点，不改变原有父子结构。
- 关系线改用独立锚点、圆角贝塞尔曲线、箭头和独立标签，不再与树枝或节点折叠按钮重叠。
- 双击关系线可就地修改关系名称；右侧仍可编辑名称、目标和删除关系。
- 普通树枝继续固定在节点中线，保持自动布局的可读性；自由主题不能创建子节点或同级节点。

## 仍值得优化的地方

1. **关系目标落点避让。** 默认新主题现在落在起点右侧；当该处已有密集分支时，下一版应探测节点边界并选择最近的空白候选位置。
2. **关系线编辑器。** 当前双击使用轻量输入框，适合快速改名；可升级为画布内标签编辑器，支持拖动标签位置、颜色和线型。
3. **大图性能。** 已启用视口内渲染，但长文本节点、批量布局和关系线重绘仍需要性能基准与更细粒度的 memo 化。
4. **多端一致性。** 桌面端、本地草稿、云端手动同步之间还缺少明确的冲突预览与恢复流程。
5. **关系的检索能力。** 需要在搜索、任务中心和 Markdown 导出中让关系名称、方向与引用可见。

## 与主流思维导图产品的核心差距（表象）

| 核心能力 | MindTree 0.2.1 当前表现 | 成熟产品常见表现 | 优先方向 |
| --- | --- | --- | --- |
| 基础结构编辑 | 键盘、右键、拖拽、自动排列已具备 | 新节点落点、拖拽排序和动画都更稳定 | 优先消除布局跳变与密集节点碰撞 |
| 关系线 | 可创建、改名称、改目标、删除 | 可在画布直接拖拽端点/标签，支持多种线型与样式 | 先做端点重连和标签的画布内编辑 |
| 节点信息 | 备注、链接、附件、任务、标记、标签 | 多数还支持图标库、贴纸、摘要卡、样式继承 | 补齐可视化标记和节点样式继承 |
| 大图导航 | 折叠、居中、搜索、筛选已有 | 常见有鱼眼/概览、分支聚焦、演示路径 | 做小地图与更好的筛选高亮 |
| 文件与导入导出 | 本地保存、Markdown、JSON、图片已有基础 | 常见有 OPML、XMind、PDF/SVG、跨应用导入 | 优先补 OPML / SVG，再评估 XMind 兼容 |
| 协作与同步 | 本地优先、手动同步、版本历史 | 常见有多人协同、冲突合并、评论与分享 | 先完成个人多设备冲突处理，不急于多人实时协作 |
| AI | 问答、分支生成、幽灵续写、全图整理预览 | 常见有选区改写、引用来源、持续上下文 | 增加“选择范围 → AI 操作 → 可回滚预览” |
