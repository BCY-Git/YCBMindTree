# MindTree 1.25.0

AI 交互全面主流化：画布优先、节点锚定、面板兜底。

## 节点级 AI（画布优先）

- 选中节点浮现 AI 工具条：✨ 扩展想法（3 个子节点）、🌿 扩展分支（2-3 层结构化分支树）、更多菜单（📋 总结分支、✅ 拆解为任务、✏️ 自定义扩展、💬 向 AI 提问）。
- 生成结果直接写入画布，⌘Z 可撤销；不再停留在面板文字预览。
- 右键菜单与 ⌘K 命令面板新增同一组 AI 动作；「自定义扩展…」在节点下方弹出输入框。

## AI 工作台（面板兜底）

- 对话支持 SSE 流式输出（打字机效果）；Web 端经服务器管道化转发，桌面端自动退回非流式。
- 首屏改为欢迎语 + 建议 chips（扩展分支 / 生成行动 / 整图检查 / 探索协作 / 决策协作）。
- 协作范围改为「从 xxx ▾」chip，默认跟随画布选中状态自动推断，手动切换后锁定。
- 待沉淀 / 足迹收进面板头部图标按钮，待处理数量以角标提示。
- 生成物预览卡片内嵌对话流，发送区合并为单一发送按钮。
- 「向 AI 提问」自动打开工作台、锁定当前节点范围并预填问题。

验证：83 个前端测试文件 / 385 用例、服务端 28 用例全部通过；tsc 类型检查与生产构建通过。
