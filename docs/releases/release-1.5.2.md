# MindTree 1.5.2

1.5.2 将“建立联系”调整为 XMind 式的先预览、后落点交互。

## 新交互

- 选择节点并点击“建立联系”后，不再立即新建目标节点。
- 虚线关系线从所选节点出发，箭头端实时跟随鼠标。
- 单击已有节点，关系直接指向该节点。
- 双击画布空白处，以双击点为中心创建自由关系主题并完成连线。
- 新主题创建后立即进入文字编辑。
- 按 Esc 取消时不会留下节点、关系或撤销历史。

## 兼容能力

- 多选节点时，多条预览线仍然指向同一个鼠标落点。
- 双击落点后只创建一个共享目标。
- 已有关系线仍可拖动箭头端更换目标。
- 关系主题保持为自由主题，不改变树形父子结构。

## 验证

- 29 个测试文件、119 项测试全部通过。
- TypeScript 和 Vite 生产构建通过。
- Playwright 验证了“不立即创建”、鼠标跟随、双击落点、立即编辑与 Esc 无副作用。
- 双击位置 `(700, 300)` 与新节点中心的测量偏差小于 `0.4px`。
