# MindTree 0.4.0

0.4.0 让智能协作不只保存过程检查点，还能把稳定结果转化为可继续复用的决策记录和知识卡。

## 新增

- 决策协作生成标准决策记录。
- 探索协作生成个人知识卡。
- 长期资产的严格结构校验、树形预览、确认写入和撤销。
- 阶段检查点门槛：没有稳定检查点时不允许生成长期资产。
- 候选修改率、确认耗时和沉淀结果再次访问指标。

## 数据与兼容

- IndexedDB 自动升级到版本 9。
- 来源记录增加目标文档和目标节点索引，用于本地判断沉淀结果是否被再次访问。
- 导图 JSON 和工作区备份格式保持兼容。

## 安全边界

- 未经确认不写入导图。
- 资产写回协作会话的原始焦点，不跟随临时选中节点漂移。
- 个人理解、标准定义和待验证内容保持分区，不合并成未经验证的结论。
