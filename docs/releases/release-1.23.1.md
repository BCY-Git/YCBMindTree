# MindTree 1.23.1

## HTML 附件：预览直接长在节点上

- 拖入 `.html` / `.htm` 后，活的 HTML 预览直接内嵌显示在节点里（顶栏 + 150px 沙箱 iframe），不再是需要点开的小卡片；点击顶栏 ⤢ 仍可放大为全屏预览。
- 拖到画布空白处会自动新建一个以文件名命名的自由主题节点，并把预览挂上去——"拖进来就是一个节点"。
- 预览按需加载：只有节点进入视口才创建 iframe；滚出视口由 React Flow 卸载，滚动回来时命中缓存秒开。
- 修复：拦截浏览器对文件拖放的默认行为。此前把文件拖到画布之外（侧栏、工具栏等区域）会导致浏览器直接打开该 HTML 文件、整个应用被替换。

## 部署

- 修复服务器 `administrators_authorized_keys` ACL 泄权导致的部署密钥认证失败；发行包改由 Windows 计划任务（SYSTEM）执行，避免 SSH 会话回收杀死部署进程。
