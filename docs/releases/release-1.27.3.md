# MindTree 1.27.3

侧栏/顶栏第三轮打磨（Notion、AFFiNE、Linear 的惯例）。

## 新特性

- 「我的工作区」改为工作区切换器样式：整行可点、悬停出背景、右侧上下箭头；从顶部打开账户菜单时菜单跟随出现在工作区行下方，从底部账户卡打开仍向上弹出。
- 侧栏搜索框右侧新增 ⌘K 提示徽标，点击（或全局按 ⌘K / Ctrl K）打开全局节点搜索——顺带补上了顶栏「搜索」按钮一直展示但未实际绑定的 ⌘K 快捷键。

## 顶栏 shadcn 化

- 浮动工具栏去掉玻璃高光扫过动画和 hover 上浮/放大，只保留背景色变化。
- 圆角统一收敛（工具栏 18px → 10px、按钮 12px → 7px、品牌标 8px/3px → 6px），阴影压平，按钮 36px → 32px、字号 11px → 12px。
