# MindTree 1.26.1

画布连线与节点尺寸的修复版本。

## 修复

- 折叠计数徽标数字溢出：CSS 特异性冲突导致胶囊被压回 20px 定宽/13px 字号，恢复自适应胶囊（`styles.css`）。
- 分支分叉不对称：`nodeSize` 原按「每字符 11px」估算文本宽高，中英混排时高估行数，布局槽位大于真实卡片导致分叉点偏移。改为 canvas `measureText` 实测（markmap/plait 同款做法），行高按真实 17.4px（12px × 1.45）计算，卡片在槽位内垂直居中兜底。
- SVG 导出的文本换行与画布共用同一套实测逻辑，消除第三处重复实现。

## 改造

- 树边路径从手写 `getMindTreePath` 切换为 xyflow 官方 `getSmoothStepPath`（已在依赖内，零新增），通过 `centerX` 保留原有「主干距父节点 24~48px」的分叉轴规则；转角半径钳制、反向/共线等边角情况由上游维护。
- 连线测试从精确路径字符串断言改为几何属性断言（主干位置、镜像对称、直线场景）。

## 附件显示（并行修复，随 1.26.2 被完全放开取代）

- 图片与 HTML 附件在「结构层」语义缩放下也照常显示，不再被收成一个信号图标；只有缩到最远的「概览」层级才隐藏。选中节点行为不变。

验证：前端 391 用例全部通过，tsc 类型检查通过，生产构建通过。
