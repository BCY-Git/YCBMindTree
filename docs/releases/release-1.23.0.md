# MindTree 1.23.0

## HTML 附件与沙箱预览

- 网页端与桌面端都支持把 `.html` / `.htm` 文件直接拖进画布：落到哪个节点就挂到哪个节点，空白处落下时挂到当前选中节点（兜底根节点）。
- 节点以轻量卡片展示 HTML 附件（图标、文件名、大小），点击卡片打开全屏预览；活的 HTML 文档不进入画布，不影响节点拖拽与渲染性能。
- 预览运行在 `sandbox="allow-scripts"` 的透明源 iframe 中：内联脚本正常执行，但无法读取主应用的存储，也无法调用云同步接口。
- 桌面端新增 `mindtree-preview` 自定义协议：预览文档自带独立宽松 CSP，与主应用严格 CSP 完全隔离，避免 blob/srcdoc 方案继承主策略导致预览页内联脚本被禁。
- 桌面端关闭 Tauri 原生拖放拦截（`dragDropEnabled: false`），网页与桌面共用同一条 HTML5 拖放路径。
- Inspector 中 HTML 附件支持预览、下载与移除；文件选择器同步接受 `.html`；单个附件上限 15 MB。
- 新增 14 项纯函数测试覆盖 HTML 文件识别、类型归一化与预览地址安全校验。

## AI 助手与编辑器

- AI 助手新增智能协作工作流入口与模型连接设置面板；新增想法拓展：围绕当前节点由模型生成三个候选子主题，确认后写入导图（需已配置模型）。
- 新增编辑器偏好设置：悬浮工具栏可见性（常驻 / 悬停显示 / 隐藏）与"新增主题"按钮开关。
- 画布新增点击火花反馈；剪贴板、树边连接等交互细节修复。

## 交付

- 新增桌面 macOS 构建工作流：`v*` 标签在 Apple Silicon runner 产出 DMG 草稿，验收后手动发布。
- 本版本是"标签触发生产部署"链路的首个发行：构建 → 受保护环境部署 → 健康检查 → 失败自动回滚。
