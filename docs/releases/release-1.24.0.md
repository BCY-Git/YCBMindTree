# MindTree 1.24.0

## 可调整的工作区

- 左侧工作区和右侧属性面板支持拖动边缘调整宽度，并记住当前设备的选择。
- 双击边缘恢复默认宽度，也支持聚焦边缘后用方向键调整。
- 层级间距与同级间距移至左下角「设置 → 当前导图布局」，修改随导图保存且支持撤销。

## AI 模型切换

- 输入框右下角可直接展开模型菜单，切换已保存的模型及其服务连接。
- 提供 DeepSeek 官方模型选项，包括视觉模型；支持添加自定义兼容服务的模型。

## 流程截图转导图

- 支持上传、粘贴、拖入 PNG / JPEG / WebP 流程截图，每次一张、最大 4 MB。
- 选择支持图片输入的模型后生成树状预览，确认后插入当前节点下，支持撤销。
- 循环与跨步骤跳转使用文字标注；识别失败保留截图，方便重试。
- 调整 AI 代理请求大小限制，以支持图片请求。
