# MindTree 1.17.0

## 本次更新

- 大图概览新增层级强调：中心主题和一级分支保持主视觉，二至三级作为次级信息，四级以后退为上下文。
- 结构层同步弱化过深分支，让任务提示与主干方向更容易扫描。
- 深层节点只是降低视觉权重，不会隐藏；鼠标移入会适度恢复清晰度。
- 选中或编辑任意深层节点时，节点仍会恢复完整工作态和全部操作能力。
- 概览层隐藏普通关系线文字，只保留连接方向；选中关系后立即恢复关系名称。
- 概览层将边界退为安静的分组轮廓，并保留摘要结论、降低摘要卡片和连接线的视觉噪声。
- 概览和结构层不显示边界、摘要的删除控件，避免远景误操作。

## 稳定性边界

- 层级强调只作用于渲染样式，不修改树形布局、节点尺寸或文档结构。
- 树枝按深度渐进弱化，但路径与连接锚点保持不变。
- 导出结果不受当前语义缩放层级影响。
