# MindTree 1.5.1

1.5.1 完善了横向关系的多对一表达和目标节点调整交互。

## 新增

- 多选两个或更多节点后，工具栏显示“共同联系”。
- 一次只创建一个共享自由主题，所有新关系指向同一个目标 ID。
- 选中关系线后，可将箭头端点拖到任意已有节点。
- 关系目标修改不会改变树节点的父子结构。

## 安全边界

- 树枝连线仍然不可重连。
- 关系线只允许拖动目标端，源节点保持不变。
- 禁止关系指向自身或建立重复关系。

## 验证

- 28 个测试文件、115 项测试全部通过。
- TypeScript 和 Vite 生产构建通过。
- Playwright 真实验证了多选共享目标和关系箭头拖拽到已有节点。
