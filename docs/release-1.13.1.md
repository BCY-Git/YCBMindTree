# MindTree 1.13.1

1.13.1 修复 macOS 客户端中图片复制粘贴失败的问题。

## 修复

- 支持 Finder 中复制 PNG、JPEG、WebP、GIF、SVG、BMP、AVIF 和 HEIC/HEIF 图片文件后粘贴到选中节点。
- 兼容系统截图和浏览器复制图片使用的剪贴板 `items` 格式。
- 兼容 WebKit 将图片文件标记为普通二进制数据的情况。
- 粘贴事件目标不是普通 DOM 元素时不再抛出异常。

## 使用方式

1. 在 MindTree 中单击选择目标节点。
2. 从系统截图、浏览器或 Finder 复制图片。
3. 按 `⌘V`，图片将作为本机附件写入并显示在节点中。
