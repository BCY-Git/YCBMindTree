# MindTree 1.15.0

## 本次更新

- 一张导图仍只保留一个中心主题，同时允许存在多棵可独立编辑的自由主题树。
- 双击画布空白处，会在鼠标落点创建自由主题并立即进入编辑。
- 将中心树中的任意分支拖离原树，可把该分支及全部后代整体转为独立主题树。
- 独立主题树拖动时，所有可见后代会保持相对位置一起移动；拖回主树附近可整棵重新吸附。
- 自由主题支持新增、粘贴、折叠和展开子分支，并可在工具栏、右键菜单、命令面板和大纲中继续编辑。
- 大纲视图会完整呈现每棵自由主题树的层级，不再只显示自由主题根节点。
- 保持现有中心树节点和连接线视觉样式不变。
