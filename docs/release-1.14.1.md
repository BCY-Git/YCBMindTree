# MindTree 1.14.1

## 本次更新

- 画布上的任务状态图标不再只是展示：点击后可选择普通主题、待办、进行中或已完成。
- P1/P2/P3 优先级标记可直接点击修改，并提供“未设置”用于清除优先级。
- 点击标记会同时选中节点，确保菜单处于正确的节点层级且不会误触节点拖动或文字编辑。
- 标记菜单从图标左下方展开，避免节点靠近右侧属性栏时菜单被遮挡。
- 所有修改继续通过统一 Command 层执行，保留撤销和本地持久化能力。
