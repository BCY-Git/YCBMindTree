# 里程碑 1.13：图片可视化与附件生命周期完成状态

更新时间：2026-07-16

## 已完成

- 图片可通过剪贴板粘贴或属性侧栏文件选择器添加到当前节点。
- 节点内显示第一张图片的轻量缩略图，不改变节点宽度、主题色和树形连接算法。
- 属性侧栏显示节点的全部图片，可逐张查看和移除；非图片附件保持原有下载交互。
- 点击缩略图进入原图查看器，支持关闭按钮、背景点击和 Esc 退出。
- 图片节点自动预留高度，分支布局跟随节点真实尺寸重新计算。
- SVG 导出把本机图片转换为 Data URL 嵌入文件，离开当前设备仍能显示。
- 附件或分支删除后自动清理无引用 Blob；仍被历史版本引用的图片继续保留。
- 工作区备份继续携带本机附件 Blob，原始文件不会静默上传云端。

## 产品边界

- 节点只展示第一张图片，全部图片在资源侧栏统一管理，避免节点过度膨胀。
- 图片本体保存在本机 IndexedDB；云同步只同步附件元数据，不承诺跨设备图片可用。
- 这次只增加内容呈现能力，不改树形结构样式、连接线算法和节点宽度。
- 暂不做图片 OCR、视觉理解、批注编辑和云端图片托管。

## 验收

- 组件测试覆盖本机 Blob 读取、缩略图、原图查看和 Esc 退出。
- 布局测试覆盖图片节点高度；SVG 测试覆盖图片嵌入。
- 持久化测试覆盖无引用 Blob 回收，以及历史版本引用保护。
- 主应用 45 个测试文件、167 项测试通过；服务端 19 项测试通过。
- 生产构建通过；真实浏览器完成“添加图片 → 节点预览 → 原图查看 → Esc 退出”。

## 1.13.1 剪贴板兼容修复

- 补齐 `clipboardData.files` 读取，支持 macOS/Finder 复制图片文件后粘贴到节点。
- 保留 `clipboardData.items` 路径，系统截图和浏览器复制图片继续可用。
- 当 WebKit 把图片标记为普通二进制时，根据文件扩展名恢复正确的图片 MIME。
- 修复粘贴事件目标不是 DOM Element 时调用 `closest` 导致的异常。

## 1.13.2 桌面导出闭环

- SVG、透明 SVG、OPML 和四种 Markdown 导出统一使用 macOS 原生“另存为”面板。
- 保存面板提供默认文件名和对应格式筛选，不再静默写入下载目录。
- 保存成功后显示完整路径，并可直接在 Finder 中定位文件。
- 取消保存不报错；写入失败时显示明确错误信息。
- 浏览器环境继续回退为标准下载，并提示文件进入浏览器默认目录。
