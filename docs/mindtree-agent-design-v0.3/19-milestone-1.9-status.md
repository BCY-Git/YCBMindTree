# 里程碑 1.9：分支聚焦与专注模式完成状态

更新时间：2026-07-15

## 已完成

- 选中普通节点后可从顶部工具栏聚焦该分支。
- 导图与大纲只展示聚焦节点及其后代，并共享同一个临时聚焦状态。
- 顶部面包屑显示从中心主题到当前聚焦节点的路径，可逐级返回。
- `Esc`、工具栏“退出聚焦”或“显示完整导图”恢复全图。
- 搜索定位到聚焦范围外节点时退出聚焦并定位，不会让用户找不到结果。
- 聚焦投影只保留范围内可解释的关系、边界和摘要。
- 聚焦根节点禁止新建同级和全图自动排列，防止操作落到不可见范围。

## 数据边界

- 聚焦状态不写入 `MindMapDocument`，不产生版本与同步噪声。
- 视图投影沿用原节点 ID，编辑、任务、AI 和沉淀仍直接作用于原文档。
- 原始父子关系、手动偏移、关系线和分组不会被投影修改。

## 验收

- 子树投影、面包屑、关系和边界过滤通过自动化测试。
- 聚焦大纲专项测试确认范围外节点隐藏但原文档仍完整。
- 真实浏览器验证导图聚焦、面包屑、跨视图保持和 Esc 退出。
- 修复嵌套中央工作区后，React Flow 宽高检测无警告。
