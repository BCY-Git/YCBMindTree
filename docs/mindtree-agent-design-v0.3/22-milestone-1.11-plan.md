# 里程碑 1.11：跨导图节点链接计划

更新时间：2026-07-15

## 目标

让日报、项目、学习记录和沉淀资产之间形成可保存、可导航、可检查的连接，而不只依赖每次重新搜索。

## 批次 1：内部深链协议

- 定义稳定的文档 ID + 节点 ID 链接格式与解析器。
- 支持从当前节点复制内部链接。
- 内部链接仍作为节点资源保存，不复制目标内容。

## 批次 2：选择与导航

- 从当前节点搜索并选择另一张导图中的目标节点。
- 点击内部链接时切换文档、展开祖先并聚焦目标节点。
- 同文档链接直接定位，不产生不必要的文档切换。

## 批次 3：失效与安全

- 目标文档或节点不存在时显示“链接已失效”，不尝试打开外部地址。
- 文档复制、导入和恢复时保留链接文字，但明确内部 ID 可能需要重新绑定。
- 不在链接中包含节点正文、账号信息或云端访问凭据。

## 验收

- 协议序列化与解析测试。
- 同文档、跨文档和失效目标导航测试。
- 浏览器验证创建、点击、返回和错误提示闭环。
