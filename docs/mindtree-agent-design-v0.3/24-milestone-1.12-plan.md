# 里程碑 1.12：轻量演示模式计划

更新时间：2026-07-15

## 目标

让项目汇报、学习复盘和阶段成果可以直接从现有树结构讲述，避免为了演示复制出另一份很快过期的幻灯片数据。

## 批次 1：演示序列

- 默认按当前可见树的深度优先顺序生成演示步骤。
- 折叠节点只作为一步，不静默展开被隐藏内容。
- 支持从当前节点开始和退出后回到原视口。

## 批次 2：沉浸呈现

- 隐藏编辑工具与左右侧栏，保留主题、当前节点、路径和前后导航。
- 键盘方向键 / 空格前进，Esc 退出。
- 当前步骤突出，相关上下文保留但弱化，不修改树样式和节点位置。

## 批次 3：讲述辅助

- 备注作为演讲者提示，可选择显示或隐藏。
- 显示当前页码与总步骤数。
- 后续评估 AI 根据阶段结论生成讲述提纲，但不得自动改写原节点。

## 不做

- 第一版不实现自由排版幻灯片编辑器。
- 不复制一份“演示专用导图”造成双数据源。
- 不自动上传或发布导图。

## 验收

- 顺序、折叠边界和退出恢复测试。
- 浏览器验证全屏/普通窗口、键盘导航和侧栏恢复。
