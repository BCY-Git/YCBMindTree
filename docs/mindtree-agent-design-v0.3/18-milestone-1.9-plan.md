# 里程碑 1.9：分支聚焦与专注模式计划

更新时间：2026-07-15

状态：已完成。结果见 `19-milestone-1.9-status.md`。

## 目标

在大型导图中只处理当前分支，降低无关内容干扰，同时保持对原始完整导图的可逆导航。

## 核心行为

- 选中普通节点后可“聚焦此分支”。
- 中央画布只显示该节点及其后代，不修改或删除原导图节点。
- 顶部显示从根节点到聚焦节点的面包屑，可逐级返回。
- `Esc` 或“显示完整导图”退出聚焦。
- 搜索定位到聚焦范围外节点时，自动退出或切换聚焦范围并明确提示。
- 大纲与导图共享同一个临时聚焦状态。

## 验收边界

- 聚焦状态不写入导图文档，不制造版本噪声。
- 编辑、任务、AI 协作和沉淀仍作用于原节点 ID。
- 关系、边界和摘要只显示聚焦范围内可解释的部分。
- 退出聚焦后完整布局和用户手动偏移保持不变。
