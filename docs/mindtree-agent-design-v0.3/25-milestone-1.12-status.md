# 里程碑 1.12：轻量演示模式完成状态

更新时间：2026-07-15

## 已完成

- 从中心主题或当前选中节点开始演示。
- 按当前可见树的深度优先顺序生成讲述步骤。
- 折叠节点不会静默展开，隐藏后代不进入演示序列。
- 演示层隐藏编辑干扰，显示文档标题、路径、页码、当前主题和直接子主题。
- 支持方向键、空格、PageUp / PageDown 导航，Esc 退出。
- 节点备注可按需显示为演讲者提示，默认隐藏。
- 可进入系统全屏；退出演示后原导图、选中节点、缩放和侧栏状态不变。

## 数据边界

- 演示序列只从当前文档投影，不持久化、不复制节点、不创建第二数据源。
- 不修改原树结构、折叠状态、节点位置和主题样式。
- 备注只在用户主动显示时出现。
