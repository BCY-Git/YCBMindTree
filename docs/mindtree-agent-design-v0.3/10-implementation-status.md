# 0.3 实施状态

更新时间：2026-07-15

## 已完成的核心闭环

- 当前节点/子树的受控上下文构建，含节点语义、硬上限、裁剪提示和开发模式预览。
- 事实、成果、任务、问题、决策、知识、想法七类结构化候选。
- Zod 校验、来源 ID 与目标 ID 白名单、候选上限和重复指纹。
- 待沉淀收件箱：逐条/批量选择、修改类型/动作/文本/去向、忽略和稍后处理。
- `keep`、`create`、`update`、`complete`、`append-note` 五种动作。
- 单导图原子命令、差异预览、撤销/重做与批次状态联动。
- 跨导图有限目标推荐、版本检查、单事务写入、来源追踪和整体撤销。
- Dexie 独立保存批次、来源、跨图撤销日志、协作会话和本地匿名指标。
- 工作区备份/恢复包含批次、来源与协作会话；冲突恢复时同步重映射引用。
- 从旧版 IndexedDB 升级到当前数据表的自动化测试。
- 探索/决策/交付协作会话、目标/约束/验收标准、阶段与结构化检查点。
- 检查点可继续生成沉淀候选；普通树不写入协作状态。
- 随手记、日期分支和完成任务组的纯本地低打扰提示；不会自动调用模型。
- 本地聚合候选生成、接受、忽略、重选目标、重复、应用和失败指标，不保存原文。

## 安全与产品边界

- AI 生成仅形成候选；未经确认不修改导图。
- 原始记录不会被沉淀流程删除、移动或覆盖。
- 跨导图任一目标变化都会阻止整批写入，不产生半完成结果。
- API Key、附件二进制和无关工作区内容不进入沉淀上下文。
- 单图导出不包含候选、来源或协作会话；工作区备份包含这些本地长期状态。

## 明确不属于 0.3 的内容

- 多 Agent、向量数据库、无限自主循环。
- 未经确认的后台模型调用或自动写入。
- 自动整理全部历史导图。
- 节点自动删除、合并或大范围移动。
- 服务端 MCP 的沉淀批次管理工具；0.3 的 UI 与领域服务不依赖 MCP。

## 验证

- 客户端协议、上下文、固定场景、命令、历史、备份、迁移和协作测试。
- 服务端同步、权限、MCP 节点兼容与构建测试。
- 客户端和服务端 TypeScript 生产构建。

真实模型提取质量仍需要用用户的日报、学习、项目和临时想法持续观察；产品已记录本地聚合指标供后续调整，不以候选数量作为成功标准。
