# 里程碑 0.4 实施状态

更新时间：2026-07-15

## 目标

把协作会话中已经形成的稳定理解和决策，转化为可以继续复用的树形资产，而不是只留下聊天和检查点。

## 已完成

- 决策模式可从阶段检查点生成结构化决策记录。
- 探索模式可从阶段检查点生成结构化知识卡。
- 决策记录包含最终决策、选择原因、候选与取舍、适用条件、重新评估条件和下一步。
- 知识卡区分个人理解、标准定义、关键边界、示例、常见误区和待验证问题。
- 模型响应经过严格 Zod schema、长度和节点数量校验。
- 生成结果沿用分支预览，未经确认不写入；确认后作为一次命令写入并支持撤销。
- 资产始终写入协作会话的焦点节点，避免用户切换选择后写错位置。
- 没有阶段检查点时禁用长期资产生成，防止模型为不稳定内容填空。
- 本地指标新增候选修改、确认耗时和沉淀结果再次访问；不保存原文。
- IndexedDB 升级到版本 9，为来源目标节点建立多值索引，旧导图自动迁移。

## 交互路径

```text
开始探索/决策协作
→ 生成并确认阶段检查点
→ 生成知识卡/决策记录
→ 核对树形预览
→ 用户确认写入焦点节点
→ 后续再次访问或继续修改
```

## 安全边界

- 模板是长期资产草稿，不会静默写入。
- 模型只能生成新分支，不能借模板删除、移动或覆盖原始节点。
- 决策与知识卡使用不同协议，避免把个人理解伪装成标准定义。
- 再次访问指标只记录来源 ID、目标 ID 和计数，不记录节点文本。

- 协作面板模式入口和检查点门槛 UI 测试。

- 客户端全量测试、生产构建和 Tauri 桌面构建。
