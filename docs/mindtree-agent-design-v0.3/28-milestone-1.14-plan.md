# 里程碑 1.14：可选起步结构计划

更新时间：2026-07-16

## 目标

为常见记录场景提供低负担起点，同时坚持“允许自然记录、AI 后置整理”，不把模板变成新的纪律要求。

## 第一批候选

- 空白导图。
- 日报 / 周报：完成、进行中、问题、下一步。
- 项目推进：背景、目标、约束、任务、风险、验收。
- 学习理解：概念、个人理解、边界、例子、待验证。
- 决策记录：问题、候选、标准、选择、重评条件。

## 交互原则

- 新建时默认仍可直接使用空白导图。
- 模板只生成初始节点，不绑定强制状态机。
- 用户可删除、改名和重排所有模板节点。
- AI 可根据自然记录建议结构，但不得静默替换用户原始内容。

## 验收

- 固定模板结构和唯一 ID 测试。
- 从模板新建后可正常编辑、导出和智能沉淀。
- 浏览器验证空白入口不被弱化，模板选择不增加日常记录步骤。
