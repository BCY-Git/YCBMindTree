# 里程碑 1.10：通用交换与分享计划

更新时间：2026-07-15

## 目标

降低迁入、迁出和分享门槛，使 MindTree 的本地优先数据不会被锁在自有格式中。

## 批次 1：OPML

- 导入标准 OPML 2.0 大纲为新导图。
- 导出当前导图为 OPML，保留节点顺序、备注与折叠状态可表达部分。
- 对非法 XML、空大纲和过大文件给出明确错误，不覆盖当前导图。

## 批次 2：Markdown 导入

- 将标题和缩进列表转换为节点层级。
- 普通段落优先作为最近节点备注，不盲目创建大量主题。
- 导入前预览标题、节点数与最大深度。

## 批次 3：可视化分享

- 优先 SVG，再评估 PNG 与 PDF。
- 导出结果必须覆盖完整可见导图，而不是只截当前视口。
- 支持背景色与透明背景，并验证中文字体和关系线。

## 边界

- 每种格式先建立固定样本和往返测试。
- 不宣称无法无损表达的第三方专有字段。
- 自有 `.mindtree.json` 和工作区备份仍是完整保真格式。
