# 主流思维导图能力差距盘点

更新时间：2026-07-15

## 结论

MindTree 不应按功能数量复制 XMind、MindNode 或 MindManager。产品核心仍然是：

> 让个人以低负担方式自然记录，再由本地优先的树形工作空间和智能体，把过程信息回流为可推进、可追溯、可复用的结构。

因此优先补“阻断记录、整理、聚焦、复用”的基础能力；复杂图表、企业项目管理和实时多人协作不应抢占智能沉淀主线。

## 官方能力依据

- [XMind Outliner](https://xmind.com/user-guide/outliner-new)：导图与大纲切换、拖动调整层级、只显示分支、多格式导出。
- [XMind 产品介绍](https://xmind.com/user-guide/intro-new)：九种结构、Pitch、ZEN、Outliner、模板和主题。
- [XMind 功能页](https://xmind.com/features)：附件、图片、音频、公式、自定义主题和 PDF/PNG 等导出。
- [MindNode 功能页](https://www.mindnode.com/features)：大纲、标签、联系、任务、Focus Mode、跨文档链接和多格式交换。
- [MindNode Outlining](https://www.mindnode.com/support/guides/outlining)：大纲内编辑、排序、折叠、任务以及备注/图片/标签显示。
- [MindNode Import & Export](https://www.mindnode.com/support/guides/import-and-export)：PDF、SVG、FreeMind、OPML、PNG、Markdown 和文本。
- [MindManager 能力对照](https://www.mindmanager.com/static/mm/docs/mindmanager2020-Win-v-Mac-comparison-enA4.pdf)：大纲、甘特、时间表、模板、关系与边界、任务依赖、协作等。
- [EdrawMind 用户指南](https://edrawmind.wondershare.com/guide/EdrawMind_V12_User_Guide.pdf)：导图、大纲、看板和幻灯片等多视图工作方式。

## 差距与优先级

| 能力 | 主流普遍度 | 对 MindTree 的价值 | 当前状态 | 决策 |
|---|---:|---:|---|---|
| 可编辑大纲视图 | 很高 | 很高：适合日报、长文本与结构整理 | 1.8 已完成 | 已补齐 |
| 聚焦分支 / 专注模式 | 很高 | 很高：大树中降低干扰，便于阶段协作 | 1.9 已完成 | 已补齐 |
| OPML / Markdown 导入、PNG / SVG / PDF 导出 | 很高 | 很高：迁移、分享和长期可用性 | 1.10 已完成 OPML、Markdown 与 SVG；PNG/PDF 待按分享需求补 | 基础交换已补齐 |
| 跨文档节点链接 / 深链 | 中高 | 很高：让日报、项目、知识资产形成可导航网络 | 1.11 已完成 | 已补齐 |
| 演示 / Pitch 模式 | 中高 | 中高：汇报工作高频 | 缺失 | 1.12 优先 |
| 模板与多种布局 | 很高 | 中：有助起步，但不是沉淀核心 | 主题存在，结构模板缺失 | 分阶段补充 |
| 图片、公式、音频等富内容 | 中高 | 中：学习和会议场景有价值 | 通用附件已有 | 按真实需求补 |
| 实时多人协作 | 中高 | 低到中：当前定位是个人本地工作空间 | 账号同步已有，无实时协作 | 暂缓 |
| 甘特、资源、成本、关键路径 | MindManager 强 | 低：会把产品推向企业项目管理 | 缺失 | 不进入近期主线 |

## 1.8 选择大纲的原因

1. XMind、MindNode、MindManager 都将其作为基础视图，不是附加装饰。
2. 它与思维导图共享同一层级模型，补齐成本可控且不会破坏现有画布。
3. 对用户真实的日报、学习记录、项目过程和临时想法都有直接价值。
4. 它让 AI 生成或沉淀后的结构可以用线性方式快速审查和修改。

## 明确不做的跟随

- 不为了“九种结构”而立即重写布局引擎。
- 不把个人工具改造成甘特和资源成本系统。
- 不以静默云端上传换取协作功能。
- 不让大纲成为导图数据的第二份副本；所有编辑必须继续走统一 Command 层。
