# 里程碑 1.7：检索质量验证计划

更新时间：2026-07-15

## 目标

验证 1.6 的结构化检索是否真的能让日报、学习、项目和临时想法重新被找到。1.7 的产物是可重复的质量证据和改进依据，不是更复杂的检索技术。

## 批次 1：固定召回样本

建立四组不含私人真实原文的匿名化测试样本：

- 日报回流：从日期记录找到对应项目进展、问题和下一步。
- 学习迁移：从自然问题找到概念卡、关键边界和历史纠偏。
- 项目决策：从当前任务找到历史决策、选择原因和重新评估条件。
- 临时想法：从想法关键词找到相关项目，同时避免召回表面相似但无关的节点。

每组记录：查询意图、期望节点、允许结果、禁止结果和期望前五名位置。

## 批次 2：纯本地质量评估

新增可测试的评估器，至少输出：

- Recall@5：期望节点是否进入前五名。
- MRR：第一个正确结果的位置。
- 无关结果率：禁止结果进入前五名的比例。
- 跨图定位成功率：选择结果后是否打开正确导图和节点。

评估器只消费匿名固定样本或用户主动触发的本地测试，不上传导图内容。

## 批次 3：隐私友好的使用指标

仅记录聚合字段：

- 当前导图/全部导图范围。
- 是否使用语义筛选及筛选种类数量。
- 结果数量、点击排名、是否跨图定位。
- AI 检索返回节点数、是否为空、是否达到上限。

明确禁止记录：查询原文、节点主题、备注、链接、标签名称、模型回复和导图快照。

## 批次 4：调优与决策

先调整可解释规则：关键词拆分、主题/备注权重、路径权重、标签和来源角色权重、重复结果合并。

只有同时满足以下条件才进入本地向量索引设计：

1. 四类固定样本中的自然语言查询持续出现结构化关键词无法覆盖的漏召回。
2. 通过规则和字段权重调整仍无法达到约定的 Recall@5。
3. 可以在本地完成索引、删除、备份和隐私说明，不依赖静默上传原文。

## 验收门槛

- 四类固定样本全部进入自动化测试。
- 评估结果可重复，不依赖在线模型。
- 新指标不包含任何可还原用户原文的字段。
- 不降低 1.6 当前导图搜索和跨图定位行为。
- 完成真实使用观察前，不新增向量数据库依赖。
