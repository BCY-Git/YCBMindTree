# 里程碑 1.11：跨导图节点链接完成状态

更新时间：2026-07-15

## 已完成

- 定义 `mindtree://node` 内部链接协议，只携带文档 ID 与节点 ID。
- 节点资源面板可以搜索全部导图并链接到目标节点。
- 支持复制当前节点链接，用于粘贴到其他节点或个人记录。
- 点击内部链接时复用统一导航：切换目标导图、展开祖先并定位节点。
- 同文档内部链接直接定位，不触发多余文档切换。
- 目标文档或节点被删除后显示“链接已失效”，不会交给浏览器当作外部地址。
- 禁止节点链接到自身，并保留重复链接检查。

## 数据边界

- 不增加 `MindMapDocument` schema；内部链接继续使用既有节点资源与 Command 层。
- 链接不包含节点正文、账号信息、同步地址或凭据。
- 导图复制和通用导入不会尝试猜测或静默重写内部 ID。

## 验收

- 协议序列化、解析、有效目标与两类失效目标均有自动化测试。
- 客户端 42 个测试文件、160 项测试通过；服务端 19 项测试通过。
- 真实浏览器完成“打开资源 → 搜索节点 → 创建链接 → 点击定位”闭环，控制台无错误。
