# MindTree 智能沉淀与协作设计包

版本：0.3-design  
基线：MindTree 0.2.2  
用途：供本地编码 Agent 实施，用户负责产品与关键决策审查。

## 一句话定位

MindTree 是一个面向个人思考与工作的本地优先树形工作空间：允许用户低负担地记录日报、项目过程、学习理解和临时想法，再由智能体识别其中的任务、问题、成果、决策和知识结论，经用户确认后沉淀为可持续使用的行动与知识结构。

## 核心闭环

```text
自然记录 → 智能识别 → 候选沉淀 → 轻量确认 → 回流项目/知识 → 后续再次使用
```

## 本设计包的实现优先级

第一阶段验证“智能沉淀”，不先实现全自主 Agent：

1. 从当前节点或子树分析可沉淀内容。
2. 识别事实、成果、任务、问题、决策、知识和想法。
3. 提供待沉淀收件箱和建议去向。
4. 支持保留、新建、更新、完成、追加备注等动作。
5. 用户确认后，通过现有 Command 层原子写入并可撤销。
6. 保留来源，避免重复沉淀，不覆盖原始记录。

探索、决策、交付工作流在上述闭环稳定后接入。

## 关键产品决策

- 不要求用户先分类再记录；先允许自然输入，再由系统辅助整理。
- 原始记录是事实来源，沉淀结果不能覆盖或删除原始记录。
- “无感”指后台识别和低打扰确认，不指未经同意自动修改树。
- 日报、学习、项目和灵感共用一套识别管线，但采用不同沉淀策略。
- 工作流阶段与节点任务状态是两个维度，不能复用 `taskStatus`。
- 普通导图保持轻量；智能沉淀和智能协作均为可选能力。
- AI 修改必须经过结构校验、版本检查、差异预览和用户确认。
- 第一版不引入向量数据库、多 Agent 或无限工具循环。
