# MindTree 0.2.2：完整工作区备份与安全恢复

## 本版交付

- 顶部“导出与备份”菜单可生成 `.mindtree-backup.zip` 工作区备份。
- 备份包含导图、分类、标签、版本历史与被节点引用的附件二进制；同步 Token、登录会话和 AI Key 不会进入备份。
- 左侧“导图 → 恢复”可读取备份，并在写入前展示导图、版本、附件与同 ID 冲突数量。
- 恢复永远合并到现有工作区，不会清空或覆盖当前数据。
- 遇到同 ID 导图时，恢复模块会创建“恢复副本”，并同时重建文档 ID、版本 ID、附件 ID、节点附件引用、标签与分类映射，避免内容串号。
- 备份/恢复写入使用 IndexedDB 事务，避免出现“导图恢复成功、附件恢复失败”的半完成状态。

## 使用方式

1. 右上角下载菜单选择“导出工作区备份”。
2. 新设备或重装后，在左侧展开“导图”，点击“恢复”。
3. 选择 `.mindtree-backup.zip`，核对预览信息后选择“安全恢复工作区”。
4. 如果本机已有同一份导图，恢复结果会以“恢复副本”显示，原内容保持不变。

## 边界

- 单图 `.mindtree.json` 仍可通过“导入”处理；它不包含附件文件。
- 云端同步暂不上传附件；工作区备份是当前跨设备迁移附件的可靠方式。
- 当前不提供“清空本机后完全覆盖恢复”，避免误操作；如确有需要，可在后续设置页加入二次确认后的灾难恢复流程。
