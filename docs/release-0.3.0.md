# MindTree 0.3.0

0.3.0 将 MindTree 从“记录和编辑树”推进为“自然记录、智能识别、确认回流、阶段协作”的本地优先工作空间。

## 新增

- 智能沉淀建议与待处理收件箱。
- 单导图和跨导图的新增、更新、完成与追加备注。
- 来源追踪、重复检测、版本冲突保护和整体撤销。
- 探索、决策、交付三种智能协作会话与阶段检查点。
- 低打扰本地整理提示和匿名本地使用指标。
- 沉淀、来源与协作会话的工作区备份恢复。

## 数据与兼容

- IndexedDB 自动升级到版本 8，旧导图保持兼容。
- 工作区备份格式升级到版本 3，仍可读取版本 1 和版本 2。
- 单图文件格式不变，沉淀和协作元数据不会污染普通导图 JSON。

## 安全边界

- 模型输出必须通过结构与 ID 白名单校验。
- 所有写入均需用户确认。
- 原始记录不会被智能沉淀删除或重写。
