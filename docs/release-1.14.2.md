# MindTree 1.14.2

## 本次更新

- 打开随手记草稿时，顶栏新增明确的“删除”按钮。
- 左侧导图列表中的每份随手记草稿都提供独立删除按钮，不会误触打开草稿。
- 离开随手记时的处理对话框增加“删除这份随手记”。
- 删除前必须确认；删除后清理正文、附件、版本历史、同步绑定及相关本地 AI 工作状态。
- 删除当前随手记后自动切换到最近导图；没有其他导图时创建新的空白导图。
- 删除期间会阻止延迟自动保存重新写回已删除草稿；删除失败则恢复保存并提示原因。
