# MindTree 1.13.2

1.13.2 补齐桌面导出的路径选择和结果反馈，让用户明确控制文件保存位置。

## 改进

- 完整导图 SVG 和透明背景 SVG 使用 macOS 原生“另存为”。
- OPML、Markdown 大纲、会议纪要、任务清单和 AI 上下文使用相同保存流程。
- 自动填写文档名称、导出类型后缀和格式筛选。
- 保存成功后显示完整路径，并提供“在 Finder 中显示”。
- 用户取消保存时不产生错误；失败时显示具体原因。
- 浏览器版本仍使用默认下载目录，并明确显示下载文件名。

## 保持不变

- 工作区备份和 MindTree 导图文件继续使用原生保存面板。
- 导出操作不会修改导图、节点或附件数据。
