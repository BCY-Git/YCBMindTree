## 二、导图基础操作

- **新建子节点**：选中节点按 `Tab`，或点节点右侧的蓝色 +；空白处双击新建自由主题
- **新建同级**：`Enter`（后方）/ `Shift+Enter`（前方）
- **编辑**：双击节点，或选中后按 `F2` / `空格`；`Enter` 提交，`Esc` 取消
- **移动**：直接拖拽节点到目标位置（成为子节点或调整顺序）；`Alt+←/→` 提升/降低层级
- **折叠/展开**：点节点左侧小圆钮，或 `⌘/`
- **右键菜单**：节点上右键 = 节点操作（含 AI 区块）；空白处右键 = 画布操作（自动排列、恢复自由排布等）
- **撤销/重做**：`⌘Z` / `⌘⇧Z`，几乎所有操作（含 AI 生成）都可撤销

## 三、快捷键速查

| 快捷键 | 作用 |
|---|---|
| `Tab` / `Enter` / `⇧Enter` | 子节点 / 同级（后）/ 同级（前） |
| `⌘Enter` | 插入父节点 |
| `F2` / `空格` | 编辑选中节点 |
| `⌘K` | 命令面板（全部操作 + AI 动作，可模糊搜索） |
| `⌘F` | 搜索节点（跨导图） |
| `⌘Z` / `⌘⇧Z` | 撤销 / 重做 |
| `⌘C` / `⌘X` / `⌘V` / `⌘D` | 复制 / 剪切 / 粘贴分支 / 复制副本 |
| `⌘/` | 折叠或展开分支 |
| `⌘;` | 仅显示当前分支（再按退出聚焦） |
| `⌘R` | 回到中心主题 |
| `⌥←` / `⌥→` / `⌥↑↓` | 层级与同级排序调整 |
| `⌘=` / `⌘-` / `⌘0` | 放大 / 缩小 / 重置缩放 |
| `⌘S` | 保存为本机文件 |

> Windows 下 `⌘` 对应 `Ctrl`。

## 四、节点语义：任务、标记、标签、附件

- **任务状态**：节点上的 ○/◐/✓ 图标（待办/进行中/已完成），点击可切换；右侧属性检查器「任务」页可设优先级（P1-P3）和截止日期
- **标记与标签**：右键菜单「标记」区支持旗标/星标/风险/灵感；标签在检查器中管理，可按标签筛选画布
- **图片附件**：复制图片后直接 `⌘V` 粘贴到节点；编辑态粘贴会自动结束编辑并挂图；点中图片按 `⌘X` 删除
- **HTML 附件**：把 .html 文件拖入画布空白处自动建节点并沙箱预览
- **备注**：选中节点在右侧检查器编辑；支持 **AI 幽灵续写**（输入停顿后灰色建议，Tab 接受 / Esc 忽略）

## 五、视图与导航

- **导图 ⇄ 大纲**：顶栏菜单切换，大纲模式适合快速录入长列表
- **搜索**：`⌘F` 跨导图搜索，支持按标签/标记/任务状态过滤
- **分支聚焦**：`⌘;` 只显示当前分支，适合深挖局部
- **语义缩放**：画布左下角「层」按钮，缩小后自动隐藏细节、只留结构
- **演示模式**：顶栏菜单「开始演示」，按分支逐层放映

## 六、AI 助手

> 交互原则：**画布优先、节点锚定、面板兜底**。短任务不出画布，长对话进面板。

### 1. 节点浮动工具条（最常用）

选中任意节点，上方浮现工具条：

| 按钮 | 作用 |
|---|---|
| ✨ 扩展想法 | 生成 3 个直接子节点 |
| 🌿 分支 | 生成 **2-3 层的结构化分支树**（有层级，不是平铺列表） |
| ▾ 更多 | 📋 总结分支 / ✅ 拆解为任务 / ✏️ 自定义扩展 / 💬 向 AI 提问 |

生成结果**直接写到画布上**，不满意按 `⌘Z` 撤销。「自定义扩展」可输入要求（如"按实施步骤展开"）。

### 2. 右键菜单与命令面板

右键节点 → AI 区块（同样 6 个动作）；`⌘K` 输入 "AI" 可搜到全部动作。

### 3. AI 工作台（右侧面板）

顶栏 🪄 打开，用于多轮对话和需要审阅的生成：

- **流式对话**：回复逐字输出；范围 chip「从 xxx ▾」自动跟随画布选中（当前节点/当前导图/当前项目/知识库）
- **建议 chips**：空对话时给出扩展分支、生成行动、整图检查、探索/决策协作入口
- **生成物卡片**：AI 生成的分支/计划/整图调整以卡片形式出现在对话流里，**确认插入 / 放弃**后才写入导图
- **截图转导图**：粘贴或拖入流程截图 → 识别为可插入的分支预览（需支持图片的模型）
- **头部图标**：💬 对话 / 📦 待沉淀（带角标，审查 AI 从过程记录提炼的候选）/ 🕘 足迹（历史批次与会话）

### 4. 模型配置

面板内「连接模型」：填 OpenAI 兼容端点、模型名、API Key（仅保存在本机浏览器/桌面端，不上传第三方）。推荐 DeepSeek：`https://api.deepseek.com` + `deepseek-chat`。

## 七、云端同步与多端

- **注册/登录**：顶栏菜单 →「登录或注册账号」；数据仍是本地优先，云端只做同步副本
- **手动同步**：菜单 →「云端同步配置」，填写服务地址与 Token 后手动上传/拉取；版本冲突时会提示，不会静默覆盖
- **拉取保护**：拉取远端前自动创建「同步前备份」导图
- **扫码配对**：已登录设备生成一次性二维码，新设备扫码即可配对（二维码 5 分钟有效）
- **版本历史**：菜单 →「版本历史」，可查看/回滚本地快照

## 八、把导图交给 Agent（MCP）

MindTree 服务端内置 MCP（`/mcp`，Bearer 认证），Claude Code / Pi 等 agent 可直接读写已同步的导图：

- 读：列出导图、读取完整树、按语义搜索节点
- 写：向节点添加多级子树（先 dry-run 预览，版本锁防覆盖）、智能沉淀（预览 → 用户确认 → 一次性令牌写入）

> 注意：MCP 只能读到**已手动 push 到云端**的导图，本地未同步内容对 agent 不可见。

## 九、导入导出与备份

顶栏菜单「导出」：

| 格式 | 用途 |
|---|---|
| SVG（含透明背景） | 插图、分享 |
| OPML / Markdown 大纲 | 迁移到其他大纲工具 |
| Markdown 会议纪要 / 任务清单 | 直接贴进文档或日报 |
| AI 上下文 | 喂给外部大模型的精简结构 |
| 工作区备份 | 全部导图的完整备份（建议定期导出） |
